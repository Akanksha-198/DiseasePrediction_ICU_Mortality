# ICU Mortality Predictor

## Project Description
This project predicts ICU patient mortality using Machine Learning.

The model predicts whether a patient is likely to survive or die based on ICU vitals and clinical parameters.

## Model Used
Random Forest Classifier

## Features Used
- SOFA
- Age
- GCS
- BUN
- Creatinine
- Urine
- Lactate
- pH
- HCO3
- MAP
- HR
- PaO2
- FiO2
- MechVent
- WBC
- HCT
- Platelets
- Albumin
- Glucose
- Weight

## Tech Stack
- Python
- Scikit-Learn
- Pandas
- Tkinter

## Dataset
ICU patient clinical dataset

## Run Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python full.py
```
